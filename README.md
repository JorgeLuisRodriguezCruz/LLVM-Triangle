# Triangle Multi-Backend Compiler

Un compilador Triangle extendido que soporta múltiples backends de generación de código: TAM (Triangle Abstract Machine) y LLVM IR (LLVM Intermediate Representation).

## Características

- ✅ **Compilador de línea de comandos** con soporte para múltiples backends
- ✅ **IDE gráfico** con selección de backend integrada
- ✅ **Generación de código TAM** (compatible con el compilador original)
- ✅ **Generación de código LLVM IR** (nuevo backend)
- ✅ **Interfaz unificada** para ambos backends
- ✅ **Arquitectura extensible** para agregar nuevos backends

## Instalación y Compilación

### 1. Compilar el proyecto

```batch
build.bat
```

Este script compila tanto el compilador principal como el IDE.

### 2. Verificar la compilación

```batch
test.bat
```

Ejecuta pruebas con los programas de ejemplo.

## Uso

### Compilador de Línea de Comandos

```batch
# Generar ambos backends (TAM y LLVM IR)
java -cp "Triangle\build;ide-triangle-v1.1.src\build" Triangle.MultiBackendCompiler archivo.tri both

# Generar solo LLVM IR
java -cp "Triangle\build;ide-triangle-v1.1.src\build" Triangle.MultiBackendCompiler archivo.tri llvm

# Generar solo TAM
java -cp "Triangle\build;ide-triangle-v1.1.src\build" Triangle.MultiBackendCompiler archivo.tri tam
```

### IDE Gráfico

```batch
run_ide.bat
```

En el IDE:
1. **Crear/Abrir** archivos `.tri`
2. **Seleccionar Backend**: `Triangle > Select Backend...`
3. **Compilar**: `F5` o botón Compile
4. **Ejecutar** (solo TAM): `F6` o botón Run

### Selección de Backend en IDE

El IDE incluye un diálogo para seleccionar el backend:

- **TAM**: Genera código para Triangle Abstract Machine (.tam)
- **LLVM IR**: Genera código LLVM Intermediate Representation (.ll)  
- **Both**: Genera ambos formatos

## Ejemplos

### Programa de Prueba

```triangle
! test_program.tri
let
  var x: Integer;
  var y: Integer;
  var result: Integer
in
  begin
    x := 10;
    y := 5;
    result := x + y;
    
    if result > 10 then
      result := result * 2
    else
      result := result + 1;
      
    putint(result)
  end
```

### Salida LLVM IR Generada

```llvm
; Triangle Compiler - LLVM IR Output
; Generated by Triangle-to-LLVM Backend

; Standard Library Functions
declare i32 @printf(i8*, ...)
declare i32 @scanf(i8*, ...)

; Format strings
@.str.int = private unnamed_addr constant [4 x i8] c"%d\0A\00", align 1

define i32 @main() {
entry:
  %x = alloca i32
  store i32 10, i32* %x
  %y = alloca i32
  store i32 5, i32* %y
  %result = alloca i32
  %temp0 = load i32, i32* %x
  %temp1 = load i32, i32* %y
  %temp2 = add i32 %temp0, %temp1
  store i32 %temp2, i32* %result
  ; ... más código LLVM IR
  ret i32 0
}
```

## Arquitectura del Compilador

### 1. Frontend (Análisis)
- **Parser**: Análisis sintáctico (sin cambios)
- **Checker**: Análisis semántico (sin cambios)

### 2. Backend (Generación de Código)
- **AbstractCodeGenerator**: Interfaz común
- **Encoder**: Backend TAM original
- **LLVMEncoder**: Nuevo backend LLVM IR
- **LLVMContext**: Manejo de contexto LLVM

### 3. Mapeo de Tipos

| Triangle | TAM | LLVM IR |
|----------|-----|---------|
| Integer  | 1 word | i32 |
| Boolean  | 1 word | i1 |
| Character| 1 word | i8 |

### 4. Características Soportadas

#### ✅ Implementado
- Variables y constantes
- Expresiones aritméticas y booleanas
- Comandos de asignación
- Estructuras de control (if, while)
- Llamadas a procedimientos básicas (I/O)
- Declaraciones secuenciales

#### 🚧 En desarrollo
- Arrays y records
- Funciones definidas por usuario
- Parámetros de procedimientos
- Optimizaciones LLVM

## Extensibilidad

### Agregar un Nuevo Backend

1. **Crear clase backend**:
```java
public class NewEncoder extends AbstractCodeGenerator implements Visitor {
    // Implementar métodos visitXXX para cada nodo AST
}
```

2. **Registrar en MultiBackendCompiler**:
```java
case NEW_BACKEND:
    encoder = new NewEncoder(reporter);
    break;
```

3. **Agregar a enum BackendType**:
```java
public enum BackendType {
    TAM, LLVM_IR, NEW_BACKEND, BOTH
}
```

## Herramientas Adicionales

### Compilación Manual

```batch
# Solo el compilador principal
cd Triangle
javac -d build -sourcepath src src\Triangle\*.java src\Triangle\CodeGenerator\*.java src\TAM\*.java

# Solo el IDE
cd ide-triangle-v1.1.src
javac -d build -cp ..\Triangle\build -sourcepath src src\GUI\*.java src\Triangle\*.java
```

### Ejecución de Programas LLVM

```batch
# Compilar LLVM IR a ejecutable (requiere LLVM instalado)
llc -filetype=obj test_program.ll
clang test_program.o -o test_program.exe
./test_program.exe
```

### Debugging

```batch
# Ver código TAM desensamblado
java -cp "Triangle\build" TAM.Disassembler test_program.tam

# Ver código LLVM IR
type test_program.ll
```

## Limitaciones Actuales

- Soporte limitado para arrays y records en LLVM backend
- Sin optimizaciones LLVM avanzadas
- I/O básico únicamente
- No hay manejo de errores de runtime en LLVM
